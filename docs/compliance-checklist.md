## 1. Data Protection Commission registration (do this first)

Every organisation processing personal data in Ghana must register with the Data Protection Commission. You are collecting names, phone numbers and emails through the website and the CRM, so this applies.

**Penalty for not registering:** fine up to 250 penalty units, up to two years' imprisonment, and the Commission can order you to stop processing data.

**Who registers:** Carlson Capital Ltd, as the data controller named in the privacy notice. If Gotham Consult has its own registered entity, register it too.

**Where:** dataprotection.org.gh → Registration.

**What they ask for:**

| Item | Where it comes from |
|---|---|
| Certificate of incorporation and Form 3 | Registrar of Companies |
| TIN | GRA |
| Registered office address and contact details | Company records |
| Name and contact of the person responsible for data protection | Nominate one: Uffe or Joy |
| Description of the personal data processed | Names, job titles, company details, emails, phone numbers, event registrations, payment references |
| Purposes of processing | Event registration, client service delivery, invoicing, marketing with consent |
| Categories of people | Event attendees, clients, enquirers |
| Whether data leaves Ghana | Yes: hosting and email providers, including in the EU |
| Security measures | Password access, role-based permissions, audit log, encryption in transit, payment identifiers stored separately |
| Retention periods | Registrations 3 years, financial records 6 years, enquiries 12 months |
| Fee | By sector classification, quoted at application |

**After it's issued:** send me the certificate number and I'll publish it on the privacy page, replacing the "registration in progress" line.

**Renewal:** annual. Set a reminder; the certificate can be renewed from three months before expiry until seven days after.

## 3. VAT position

Confirm for each entity:

- Is it VAT-registered? From 1 January 2026 the rate is 20%, with a registration threshold of GHS 750,000 for goods.
- If yes: all published prices must state whether VAT is included, and invoices must be proper VAT invoices issued through the approved system. E-VAT penalties run up to GHS 50,000 or three times the tax.
- If no: nothing to change; the site already says VAT is charged only where the law requires it.
